# De Harmonia Restituta — digital edition

A standalone non-fiction book site by Charles Hadley. It is separate from Continuum and the Cyberwave Homesite.

## Read and deploy

Open `index.html` to choose the reading guide, Books I–III, or the Cosmograph. For a website, serve all six HTML files together from the root of an HTTPS site. There is no build step or database. The site uses Google Fonts when online; fallback fonts remain available offline. A link in Book III opens the separate Cybernetic Tuning Fork website.

All six site files were verified byte-for-byte against a ZIP downloaded back from this private repository. The six pages returned HTTP 200 in a local preview and the reading guide opened. The owner should still check the full text, diagrams, interactions, mobile layout, and outbound links after deployment. No domain or DNS change has been made.
